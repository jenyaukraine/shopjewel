# Changelog

## 2.1.1 — 2026-07-31

- Unified the product, extension and archive names as NOVERAILE.
- Removed the development update-feed URL and documented Marketplace-delivered updates.
- Kept saved AI and Stripe secrets out of the administrator page HTML.
- Added newsletter rate limiting and clearer external-service disclosures.

## 2.1.0 — 2026-07-31

- OpenCart 4.0.2.3 and 4.1.x compatibility.
- Auto, Light and Dark storefront modes with a saved visitor preference.
- Page Builder, Mega Menu, progressive catalog filters and optional One Page Checkout.
- Reviewed AI Product Description and AI SEO workflows through a configurable HTTPS provider.
- Core-safe event integration without replacing OpenCart files.

## 1.2.0 — 2026-07-31

- Added reproducible package validation.
- Made demo data, payment and shipping helpers opt-in.
- Added support for regular merchant catalog records.
- Added configurable storefront identity and consent-aware forms.

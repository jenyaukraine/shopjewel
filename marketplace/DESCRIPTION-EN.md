# 6MOMENTS Universal Commerce Suite for OpenCart 4.x

An universal premium suite for fashion, beauty, jewelry, home, gifts and other visual catalogs. Suggested license price: **$129** (positioning range $79–149). It installs through **Extensions → Installer**, uses OpenCart events instead of modifying core files, and works with existing merchant products.

## Sales-ready checklist — implemented

- ✅ **OpenCart 4.x:** OpenCart 4.0.2.3 and the current 4.1.x line, without replacing core files.
- ✅ **Light and dark storefront:** Auto follows the visitor system preference; the manual choice persists locally.
- ✅ **Fully responsive:** home, catalog, product, cart, checkout, account and blog layouts from 360 px to desktop.
- ✅ **Core Web Vitals foundation:** LCP preload/priority, below-fold lazy loading, stable image ratios, reduced motion and deferred rendering for long pages.
- ✅ **SEO, Blog and MegaMenu compatibility:** canonical links, analytics, platform assets and scripts are retained; the Blog route and native/MegaMenu output are configurable; a view already claimed by another extension is left untouched.
- ✅ **Regular updates:** stable JSON feed, changelog, weekly OpenCart 4 branch checks and automated dependency-update PRs.

## Highlights

- Visual Page Builder for homepage section order, visibility and hero copy.
- Catalog-powered Mega Menu with configurable promotional link.
- Progressive AJAX facets, ranges, sorting and pagination with browser history and no-JavaScript fallback.
- Responsive One Page Checkout for customer, delivery, payment and confirmation steps.
- AI Product Description and AI SEO via a server-side OpenAI-compatible API, always requiring review before publication.
- Premium responsive home page, catalog, product, cart, checkout, account, blog and information layouts.
- Works with normal OpenCart products, categories, options, prices, stock, currencies and languages.
- Configurable storefront brand name, contact details, Instagram URL and legal information.
- Search suggestions, rich catalog filtering, product zoom, gift hints, newsletter capture and product sets.
- Optional one-click demo catalog; normal installation does not delete or replace merchant data.
- English storefront copy plus bundled German, Czech, Russian and Ukrainian extension translations.
- Optional Stripe Checkout and configurable DHL/DPD flat-rate helpers, disabled by default.
- No OpenCart core files are replaced.

## Compatibility

- OpenCart 4.0.2.3 and 4.1.x
- Automatically checked against OpenCart 4.0.2.3 and 4.1.0.3; production tested with PHP 8.3 and MariaDB/MySQL
- A clean OpenCart installation is recommended for importing the optional demo content

## Installation

Upload `sixmoments.ocmod.zip` in **Extensions → Installer**, install **6MOMENTS Storefront Theme** under Modules, configure the storefront, then enable it. Demo content is a separate, explicit action in module settings.

Documentation and preview images are included in the download. Stripe, DHL and DPD accounts or API services are not included.

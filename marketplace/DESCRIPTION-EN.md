# NOVERAILE Commerce Suite for OpenCart 4.x

NOVERAILE is a storefront suite for visual catalogs such as fashion, beauty, jewelry, home and gifts. It installs through **Extensions → Installer**, uses OpenCart events and does not replace core files.

## Included features

- Page Builder with reorderable homepage sections and editable hero content.
- Catalog-driven Mega Menu and a configurable native menu output slot.
- Progressive catalog filters for facets, price, stock, sorting and pagination, with browser-history and a no-JavaScript fallback.
- Optional responsive One Page Checkout.
- Consistent polished light storefront styling.
- Responsive home, catalog, product, cart, checkout, account, blog and information templates.
- Search suggestions, product zoom, gift hints, newsletter consent capture and product bundles.
- Optional demo catalog installed by a separate administrator action; a regular installation does not delete or replace merchant catalog data.
- English, German, Czech, Russian and Ukrainian extension strings.
- Optional Stripe Checkout and configurable DHL/DPD flat-rate helpers, disabled by default.

## AI disclosure

AI Product Description and AI SEO tools are optional and disabled until the merchant supplies an API key. When an administrator requests a draft, selected product fields are sent to the merchant-configured OpenAI-compatible HTTPS endpoint and model. The draft is shown for review and is not published until an administrator applies it.

## Compatibility and requirements

- OpenCart 4.0.2.3 and 4.1.x; release checks target 4.0.2.3 and 4.1.0.3.
- OpenCart 3.x and OpenCart Cloud packages are not supported by this download.
- A clean or staging store is recommended for optional demo content.
- Third-party accounts, contracts, fees and service availability for Stripe, DHL, DPD and the configured AI provider are not included.

## Installation

Upload `noveraile.ocmod.zip` in **Extensions → Installer**, install **NOVERAILE Commerce Suite** under Modules, configure it, and enable only the features you need. Documentation, license terms and changelog are included.

# Чек-лист публикации в OpenCart Marketplace

Технический архив уже готовится автоматически. Перед отправкой карточки на модерацию продавцу остаётся:

1. Подтвердить права на все фото, иллюстрации, тексты, название и товарные знаки. При необходимости отредактировать `LICENSE.txt` с юристом.
2. Указать реальный support email и URL разработчика в профиле OpenCart Marketplace.
3. Развернуть публичные storefront/admin demo. В admin demo нельзя оставлять рабочие Stripe-ключи и персональные данные.
4. Для Image загрузить `marketplace/assets/noveraile-thumbnail-260x152-v1.jpg`, для Banner — `marketplace/assets/noveraile-banner-710x380-v1.jpg`. Скриншоты интерфейса добавлять отдельно и только без ключей, персональных данных и чужих брендов.
5. Вставить текст из `DESCRIPTION-EN.md`, выбрать категорию **Themes** и отметить только проверенные версии OpenCart **4.0.2.3** и **4.1.0.3**.
6. Загрузить именно `release/noveraile.ocmod.zip`. Имя файла должно оставаться `noveraile.ocmod.zip`, потому что OpenCart использует его как код каталога расширения.
7. Проверить цену, срок поддержки и правила возврата в кабинете продавца. Не обещать функции, сервисы или сроки обновлений, которых нет в описании релиза.
8. Перед каждым обновлением изменить версию в `opencart/noveraile/install.json` и `CHANGELOG.md`, затем пересобрать релиз.

Команда сборки:

```powershell
npm run build:opencart
```

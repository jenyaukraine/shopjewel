# Чек-лист публикации в OpenCart Marketplace

Технический архив уже готовится автоматически. Перед отправкой карточки на модерацию продавцу остаётся:

1. Подтвердить права на все фото, иллюстрации, тексты, название и товарные знаки. При необходимости отредактировать `LICENSE.txt` с юристом.
2. Указать реальный support email и URL разработчика в профиле OpenCart Marketplace.
3. Развернуть публичные storefront/admin demo. В admin demo нельзя оставлять рабочие Stripe-ключи и персональные данные.
4. Загрузить изображения из `artifacts/screenshots`; для обложки использовать `home.png`, для мобильного превью — `mobile-home.png`.
5. Вставить текст из `DESCRIPTION-EN.md`, выбрать категорию **Themes** и заявить проверенную совместимость OpenCart **4.0.2.3–4.1.x**.
6. Загрузить именно `release/sixmoments.ocmod.zip`. Имя файла должно оставаться `sixmoments.ocmod.zip`, потому что OpenCart использует его как код каталога расширения.
7. Стартовая цена — **$129**. Для launch-sale можно использовать $99; ниже $79 пакет уже теряет premium-позиционирование. Указать срок поддержки и правила возврата в кабинете продавца — эти коммерческие условия не зашиваются в архив.
8. Перед каждым обновлением изменить версию в `opencart/sixmoments/install.json` и `CHANGELOG.md`, затем пересобрать релиз.

Команда сборки:

```powershell
npm run build:opencart
```

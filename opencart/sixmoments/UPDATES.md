# Update policy

The stable update channel is `https://katya-dev.duckdns.org/updates/sixmoments.json`.

- OpenCart 4.0.2.3 and 4.1.x compatibility is checked weekly and on relevant changes.
- Security and compatibility fixes are released as patch versions.
- Feature releases use semantic versioning and include migration notes in `CHANGELOG.md`.
- The extension never auto-overwrites store files or settings; merchants install reviewed packages through the OpenCart Installer.

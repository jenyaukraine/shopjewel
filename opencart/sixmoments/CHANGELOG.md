# Changelog

## 2.1.0 — 2026-07-31

- Added OpenCart 4.0.2.3 compatibility alongside OpenCart 4.1.x.
- Added Auto, Light and Dark modes with a persistent visitor switch.
- Added LCP image preload/priority, lazy loading, dimensions and deferred below-fold rendering.
- Added configurable Blog routes and an opt-in native OpenCart/MegaMenu output slot.
- Made template events extension-safe by preserving routes already claimed by another module.
- Added a stable update feed and scheduled compatibility/dependency checks.

## 2.1.0 — 2026-07-31

- Universal Page Builder with ordered, toggleable homepage sections and editable hero copy.
- Catalog-driven Mega Menu and extension-safe native menu compatibility mode.
- Progressive AJAX catalog filtering, sorting and pagination with history and GET fallback.
- Optional responsive One Page Checkout.
- Server-side AI Product Description and AI SEO studio with review-before-publish workflow.
- Light/dark mode, OpenCart 4.x compatibility and updated marketplace positioning.

## 1.2.0 — 2026-07-31

- Marketplace-ready OpenCart 4.1 package and release validation.
- Safe opt-in activation and separate demo content installer.
- Existing merchant products and categories are supported without a model prefix.
- Configurable storefront brand name and neutral contact defaults.
- Safer newsletter and gift-hint endpoints.
- Asset URL and uninstall-event fixes.
